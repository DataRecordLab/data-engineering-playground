DataCraftは「データエンジニアリングのシミュレーター」。Progateではなくシミュレーター。

**Vision**: データの流れを、誰もが理解できる世界へ  
**Mission**: データパイプラインの重荷を取り除く  
**Values**: Experience First / Design Before Build / Learn by Breaking / Open Data Culture

**学習思想**: 体験する → 行動する → 理解する（「壊して学ぶ」が核心）

**フェーズ構成**:
- Phase 0（真のMVP）: 4ノードのみ（CSV Source / Filter / Aggregate / Table Output）でデータが流れる体験を作る。認証・Supabase・AI不要。
- Phase 1: Quest 1「売上が見えない」（ECサイト・初級）全5ステージ。ゲーム要素・認証・AIレビュー込み。
- Phase 2以降: クエスト拡張（SaaS / 医療 / 金融）

**現フェーズ**: ドキュメント完成・実装未着手（2026-06-19時点）

**How to apply:** 実装はPhase 0から着手。Phase 0が動く前にSupabase・AI・ゲーム要素に手をつけない方針。
