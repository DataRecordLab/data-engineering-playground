# GAME_DESIGN.md — ゲーム設計書

## 設計の大原則

> **コードを書くゲームではなく、データ基盤を設計・構築するゲーム**

SQLは手段に過ぎない。プレイヤーが感じるのは「パイプラインを設計している感覚」。

---

## 世界観：DataCraft Agency

### 設定
プレイヤーはデータエンジニアリング専門エージェンシー「DataCraft Agency」の新人エンジニア。
毎日様々な業界のクライアントから「データ課題」が届き、クエストとして受注・解決する。

### なぜエージェンシー形式なのか
- EC・医療・SaaS・金融と業界を横断したシナリオが自然に成立する
- 「クライアントの依頼」という形で課題を与えられる
- 実務感のある「仕事の当事者」体験が生まれる
- 難易度・業界を拡張しやすい

### オープニングテキスト
```
「ようこそ、DataCraft Agencyへ。

ここでは毎日、様々なクライアントからデータの依頼が届く。
ECサイト、病院、SaaS企業、金融機関——
あらゆる業界のデータを扱う。

あなたのミッションはひとつ。
混乱したデータを整理し、
クライアントが意思決定できる状態に仕上げること。

それがデータエンジニアの仕事だ。
さあ、最初の依頼が届いた。」
```

---

## ゲームループ

```
1. クエスト選択
   業界・難易度・推定時間を見て選ぶ

2. オープニング
   クライアントの課題を読む
   → 「何を作ればいいか」を理解する

3. パイプライン設計
   ノードをビジュアルに繋いで設計する
   → 「どんな流れにするか」を考える

4. 各レイヤーの実装
   Source → Staging → Warehouse → Mart
   → 各層の役割を理解しながら進む

5. AIレビュー
   設計思想をフィードバックしてもらう
   → 「なぜその設計なのか」を深める

6. 意思決定
   完成したデータを使ってビジネス判断
   → データエンジニアの本当のゴールを体感

7. エンディング
   達成感 + 次のクエスト解放
```

## クエスト設計

### Quest 1: 売上が見えない（EC・初級）

**クライアント**: ShopNow（ECサイト）  
**難易度**: 初級  
**推定時間**: 60〜90分  
**学べる概念**: パイプライン全体像・Source/Staging/Warehouse/Mart・スタースキーマ基礎

**課題**:
```
「売上データが各システムにバラバラに存在し、
分析ができない状態です。
経営会議まで2週間。助けてください。」
```

**ゴール**: 「売上が最も落ちている曜日はいつか？」に答える

---

### Quest 2: 解約率を下げろ（SaaS・中級）

**クライアント**: TaskFlow（SaaS企業）  
**難易度**: 中級  
**推定時間**: 90〜120分  
**学べる概念**: LTV・Churn Rate・NRR・SCD・ユーザーセグメント分析

---

### Quest 3: 患者データを守れ（医療・中級）

**クライアント**: CareHub（医療機関）  
**難易度**: 中級  
**推定時間**: 120分  
**学べる概念**: 匿名化・SCD・データ品質・コンプライアンス

---

### Quest 4: 金融リスクを計算せよ（金融・上級）

**クライアント**: FinTrack（フィンテック）  
**難易度**: 上級  
**ロック条件**: Lv.5 + 中級2本完了

## ステージ設計の型

各クエストのステージは以下の型を組み合わせて設計する。

| 型 | 特徴 | 使い場面 |
|----|------|---------|
| RPG型 | ストーリー・世界観への没入 | オープニング・エンディング |
| ステージクリア型 | 明確な達成条件・達成感 | Source・Stagingの基本タスク |
| シミュレーション型 | 仕事の当事者感・上司からの指摘 | Staging・Warehouse |
| ボス戦型 | 複数の正解・設計判断を迫る | Warehouseの設計判断 |
| 意思決定型 | データを使ったビジネス判断 | Mart・エンディング |

## キャラクターシステム

### 設計方針

> **RPGスプライト × モダンデザイン**
> ピクセルアートの温かみを持ちながら、ダークテーマのプロフェッショナルな世界観に溶け込むキャラクター設計。

### スプライト仕様

| 仕様 | 値 |
|------|-----|
| ベースグリッド | 16×16 px |
| 表示サイズ | 64×64px (4x スケール) |
| ダイアログポートレート | 96×96px |
| マップ上スプライト | 32×32px (2x スケール) |
| カラーパレット | キャラクターごとに最大16色 |
| レンダリング | `image-rendering: pixelated` + SVG rect grid |
| アニメーション | CSS `@keyframes`（idle bob / talk / react） |

### アニメーション種別

| 種別 | タイミング | 内容 |
|------|-----------|------|
| `idle` | 常時 | 上下に1px揺れるループ（breathing） |
| `talk` | 会話中 | 口の開閉 + わずかな前傾 |
| `react_happy` | ★2以上獲得 | 小さくジャンプ + 色変化 |
| `react_stern` | バリデーション失敗 | 左右シェイク |
| `walk` | マップ移動 | 4フレームウォークサイクル |
| `think` | AIレビュー生成中 | 頭上に「…」表示 |

## DataCraft City — ワールドマップ

### コンセプト

> **DataCraft Cityは夜の都市。プレイヤーはデータエンジニアとして各区を訪問し、依頼を受ける。**

ダッシュボード（クエスト選択）は「区画を選んで移動する都市マップ」として体験される。
クエストは「地区」に存在し、プレイヤーキャラクターが歩いて移動する。

### 都市設計

```
╔═══════════════════════════════════════════════════════╗
║              DataCraft City — 夜景                    ║
║                                                       ║
║   [商業区]              [DataCraft HQ]   [医療センター] ║
║    🏪 ShopNow              ★ You ★        🏥 CareHub  ║
║    Quest 1 ▶             中央タワー        Quest 3 🔒  ║
║    ネオン点灯             (エージェンシー)   霧がかかる   ║
║                                                       ║
║              [テクノロジーパーク]  [金融タワー]         ║
║               💼 TaskFlow         🏦 FinTrack         ║
║               Quest 2 🔒          Quest 4 🔒          ║
║               暗め                最も高いビル         ║
║                                                       ║
╚═══════════════════════════════════════════════════════╝
```

### インタラクション設計

| 操作 | 動作 |
|------|------|
| 区画ホバー | 区画がフワっと明るくなる（scale 1.05 + glow） |
| 区画クリック（解放済み） | プレイヤーが歩いて移動 → オープニングへ遷移 |
| 区画クリック（ロック中） | プレイヤーが首を振る + ロック理由のツールチップ表示 |
| 新しい区画が解放 | 霧が晴れるアニメーション + ネオンが点灯 |

### マップ技術仕様

| 項目 | 技術 |
|------|------|
| レンダリング | SVG ベース（スケーラブル・アクセシブル） |
| 建物シルエット | SVG `<path>` でピクセルアート風シルエット |
| ネオン効果 | CSS `filter: drop-shadow()` + `@keyframes` glow パルス |
| プレイヤー移動 | CSS `transition: transform` でスムーズな位置移動 |
| 霧効果（ロック） | SVG `<filter>` で feGaussianBlur + CSS opacity |
| 背景 | グラデーション夜空 + 星のパーティクル（CSS） |
